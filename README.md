# 🏥 Hospital Appointment & Patient Management System (MERN Stack)

A full-stack web application for managing hospital operations including patient appointments, doctor management, queue system, and role-based dashboards for Admin, Doctor, and Patient.

---

## 🚀 Live Demo

🌐 Frontend:
https://hospital-appointment-patient-management-system-pvqo-6m7yql7gs.vercel.app

🔗 Backend API:
https://hospital-appointment-patient-management.onrender.com

---

## 🛠 Tech Stack

- Frontend: React.js, Vite, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT (JSON Web Token)
- Deployment: Vercel (Frontend), Render (Backend)

---

## 👨‍⚕️ Features

### 🧑 Patient
- Register & login system
- Book doctor appointments
- View medical records
- Check appointment status

### 👨‍⚕️ Doctor
- View assigned patients
- Manage appointments
- Update prescriptions
- View queue system

### 👨‍💼 Admin
- Manage doctors and patients
- View system analytics
- Control appointments
- Monitor hospital workflow

---

## 🔐 Authentication
- Secure login using JWT tokens
- Role-based access control (Admin / Doctor / Patient)
- Protected routes

## ⚙️ Setup Instructions

### 1. Clone repository

git clone https://github.com/pranathi-555/Hospital-Appointment-Patient-Management-System.git

### 2. Install dependencies
Backend
cd Backend
npm install

Frontend
cd Frontend
npm install

### 3. Run project
Backend
npm start

Frontend
npm run dev
